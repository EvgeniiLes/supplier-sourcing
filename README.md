# Снабженец-ассистент

Сервис для поиска и сравнения поставщиков продуктов питания: ингредиенты, готовая продукция, упаковка.
Вводите товар и город, получаете карточки поставщиков с контактами, условиями и оценкой. Дальше шорт-лист, письмо-запрос КП, выгрузка в Excel и, когда поставщики ответят, загрузка их КП: сервис распознаёт предложение, привязывает к поставщику и показывает, как менялись цены.

**Главный принцип: никаких выдуманных данных.** У каждого поля есть ссылка на страницу и дословная цитата. Если на сайте поля нет, сервис пишет «не указано — уточнить» и добавляет вопрос в письмо поставщику. То же для КП: цена принимается, только если она найдена в тексте документа.

## Что умеет

| Этап | Возможности |
|---|---|
| Поиск | категория + город, фильтры (документы, минималка, доставка в регион), живой поиск и демо-режим, результаты появляются по мере разбора сайтов |
| Выбор | карточки и таблица сравнения, сравнение 2–6 выбранных, сортировка, поиск по результатам, «откуда взято» (цитата) у каждого поля |
| Оценка | прозрачные правила 0–100, разбор по баллам («Как посчитана оценка»), свои приоритеты ползунками, пересчёт на лету |
| Решение | шорт-лист со статусами и заметками, письмо-запрос КП поставщику и общее письмо всем из шорт-листа, экспорт в Excel/CSV |
| Ответы | загрузка КП (PDF, Word, Excel, письмо .eml, текст, фото/скан), автоопределение поставщика, история КП, динамика цен |
| Поделиться | ссылка на результаты поиска (`/#s=ID`), вместе с выбранными приоритетами |

## Как это работает

```
запрос (товар + регион + фильтры)
  → запросы: «товар хорека город» первым (к любому запросу добавляется сегмент покупателя, чтобы выдача была про
    поставщиков для общепита, а не про розницу; если «хорека» уже есть в запросе, не дублируется), затем буквальный
    «товар город» и 3 формулировки Claude Haiku, которые не сужают предмет поиска; для общей категории («хорека»)
    ищутся оптовые поставщики и дистрибьюторы сегмента
  → поиск: Яндекс (Yandex Search API, если заданы ключи; регион по коду города) и Tavily (country=russia);
    выдачи сливаются по кругу, Яндекс приоритетнее; недоступный источник не ломает поиск, а виден в статусе
  → отсев: агрегаторы, маркетплейсы, реестры компаний, зарубежные: домены в зоне .ua
    (настраивается `EXCLUDED_TLDS`) и сайты с телефоном +380 или ценами в гривнах (до обращения к модели)
  → загрузка главной + страниц «контакты / доставка / опт / документы»
    и до двух PDF-прайсов или каталогов с сайта (по слову «прайс/каталог» в ссылке; правила и оферты пропускаются)
  → Claude Haiku извлекает поля по строгой схеме (tool use), к каждому — цитата и URL
    модель знает запрос и возвращает отдельно цены именно на искомый товар (query_prices)
  → проверки кодом (без LLM):
        цитата реально есть на странице, иначе поле отбрасывается
        телефон: формат РФ и цифры есть на странице; email: валидный и есть на странице
        цена на искомый товар: цитата найдена, цена есть в цитате, название относится к запросу
        (прочие товары, например напитки при поиске сливок, отбрасываются)
        ИНН берётся регулярным выражением
        дубли склеиваются по ИНН и телефону
  → оценка по правилам с понятными причинами («+ в вашем регионе; − нет цен»)
  → SQLite: кэш страниц, поставщики, результаты, шорт-лист, КП

загрузка КП (файл или текст письма)
  → docs.py: текст из PDF / docx / xlsx / eml / txt / html; скан или фото уходят в Claude как есть
  → Claude Haiku: поставщик, условия, позиции с ценой и дословной цитатой (tool use)
  → проверки кодом: цитата и цена найдены в тексте документа, ИНН/почта/телефон тоже
  → привязка к поставщику кодом, не моделью: ИНН, сайт, почта, телефон; при сомнении выбирает человек
  → сравнение с предыдущим КП: ▲ подорожало, ▼ подешевело, новая позиция, убрано из прайса
```

## Почему веб-сервис

Сравнивать поставщиков удобнее таблицей. Шорт-лист со статусами и заметками нужен в течение нескольких дней, а ссылкой можно поделиться с коллегой. Telegram-бот подходит позже как канал уведомлений («пришёл ответ», «цены выросли»), но не как основной экран.

## Оценка

Прозрачные правила, а не «чёрный ящик». По умолчанию максимум 100 баллов: регион 30, контакты 20, минимальный заказ 15, документы 15, доставка 10, цены 10. Неизвестное поле не штрафуется нулём «молча»: оно попадает в минусы и в вопросы письма. Вес каждого критерия пользователь меняет ползунками, оценка и порядок пересчитываются.
Фильтры (нужны документы, минималка не больше N кг, доставка в мой регион) скрывают не подошедших, но их можно показать.

## Цены на искомый товар

У большинства поставщиков цены публично не выложены, их присылают по запросу. Поэтому сервис не подменяет цены «любыми примерами с сайта»:
- В карточке «Цены на «сливки»» показаны только позиции искомого товара, у каждой источник и цитата. Если цен на этот товар на сайте нет, так и написано («запросить КП»), а в письмо поставщику добавляется просьба назвать цену именно на этот товар.
- Цены на запрос считаются отдельно для каждого поиска: другой запрос не затирает результаты прошлого.
- **Единица цены не выдумывается.** Она принимается, только если написана рядом с ценой («816 ₽/кг») или объявлена в заголовке прайса («Цена за кг»). Иначе в карточке стоит «ед. цены не указана» и фасовка: цена без единицы не делится на вес мешка, потому что неизвестно, за что она. Цена за кг/л рассчитывается (с пометкой «расчёт») только когда цена явно «за штуку» и известен вес, и не для посуды и упаковки.
- Критерий оценки «Цены на искомый товар» даёт полный балл за найденные цены на товар, малую долю, если на сайте есть прайс или цены на другое, и ноль, если цен нет.
- Можно сортировать по цене на запрос (сравниваются цены в самой частой единице: кг, л, шт), а в таблице сравнения есть колонка «Цены на запрос». Цены в разных единицах между собой не сравниваются.

## Регион: доставка и присутствие

Два разных вопроса, на оба отвечает текст сайта, а не адрес офиса:
- **Доставка в мой регион.** Модель получает ваш регион и выносит вердикт «заявлена / точно нет / не указано» с цитатой («доставка только по Москве и МО» это «нет» для Казани). Цитату проверяет код: нет в тексте или она не про это (для «да» по доставке в ней должен быть ваш регион или «по России»), значит вердикт «не указано». Три галочки, их можно сочетать: «Убрать тех, кто точно не возит» (по умолчанию), «Доставка в ваш город» (подтверждением считаются вердикт «да», доставка по всей России, регион в списке работы или адрес в вашем городе; строже первой, поэтому они снимают друг друга) и «Представитель в городе». Скрытые не пропадают: их можно показать кнопкой «Не прошли фильтры».
- **Представитель в моём городе.** Оставляет только тех, у кого указан адрес, склад, производство или филиал именно в вашем городе (хоть один из нескольких адресов). Доставку это не заменяет и наоборот. Вердикта «нет» здесь не бывает: отсутствие адреса на сайте ничего не доказывает, поэтому без подтверждения поставщик просто не проходит этот фильтр.
- Подтверждённое присутствие в городе даёт максимум баллов за регион, подтверждённая доставка чуть меньше. Если офис в городе есть, пометка «не доставляет» не приговор.
- В карточке блок «В вашем регионе «Казань»» показывает оба вердикта с цитатами и ссылками, а в письмо поставщику, у которого это не подтверждено, добавляется вопрос про ваш город.

## Отзывы клиентов

Отзывы Яндекс Карт программно не отдаются (открытого API нет), парсить Карты запрещено правилами, поэтому читаются открытые страницы:
1. Яндекс-поиск находит «название + город + отзывы»; берутся страницы отзовиков и карточек организаций (2ГИС, Зун, Флампа, Яндекс Отзывы и др.), только чужие сайты.
2. Страница принимается, если в тексте есть отличительное слово из названия или домена (общие слова вроде «хорека» и «сервис» не считаются) и, для карточек филиалов, указан ваш город: отзывы филиала в другом городе не подмешиваются.
3. Claude Haiku пишет резюме на 2–3 предложения, плюс до трёх похвал и жалоб; у каждой цитата. Код проверяет, что цитата есть на странице, иначе пункт отбрасывается; рейтинг показывается, только если он дословно есть в цитате. Нет подтверждённых пунктов, значит «отзывов не нашли».
- Отзывы кэшируются на 14 дней и обновляются кнопкой «обновить». Сбой поиска отзывов карточку не ломает и не запоминается как «отзывов нет».
- Отзывы не входят в оценку 0–100: это справка для решения. Часть отзовиков закрыта капчей, поэтому покрытие неполное.

## КП и динамика цен

- **Поставщик определяется кодом.** Модель только достаёт из документа ИНН, сайт, почту, телефон и название; сопоставление с базой делает код. Автопривязка срабатывает при совпадении ИНН, сайта, почты или телефона; по одному похожему названию сервис ничего не привязывает. Бесплатные почтовые домены (gmail, mail.ru…) за признак не считаются. Если уверенности нет, сервис предлагает кандидатов или создание нового поставщика.
- **Позиции сопоставляются по названию.** Числа в названии (вес, жирность) должны совпадать: «Сыр 2 кг» и «Сыр 5 кг» разные позиции. Единицы измерения сверяются: цена за кг и за упаковку не сравниваются, а помечаются «другая ед. изм.».
- **Предупреждения.** Если в КП разная валюта или в одном цены с НДС, а в другом без, сервис об этом пишет.
- **Что не делает.** Не читает почтовый ящик сам: КП загружает человек (файл или текст письма). Подключение IMAP/Gmail — следующий шаг.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt     # Linux: .venv/bin/pip
copy .env.example .env                              # впишите ключи
.venv\Scripts\python -m uvicorn app.main:app --port 8000
```

Откройте http://localhost:8000. Без ключей работает демо-режим (готовые результаты из `demo/`) и пример КП.

Переменные окружения: `ANTHROPIC_API_KEY`, `TAVILY_API_KEY`, `YANDEX_SEARCH_API_KEY` и `YANDEX_FOLDER_ID` (Яндекс-поиск, необязателен; живой поиск работает, если есть Claude и хотя бы один из источников), а также `MODEL_EXTRACT`, `MODEL_WRITE`, `MAX_SUPPLIERS`, `LIVE_DAILY_LIMIT` (дневной лимит живых поисков и перепроверок, по умолчанию 20), `OFFER_DAILY_LIMIT` (дневной лимит распознаваний КП, по умолчанию 10), `EXCLUDED_TLDS` (зоны, сайты из которых не показываем, по умолчанию `ua`; через запятую), `DB_PATH`. Загруженные КП лежат в `data/offers/` рядом с базой.

### Ключ Яндекс-поиска

Нужен аккаунт в Yandex AI Studio (aistudio.yandex.ru): создайте организацию (появится каталог `default`), привяжите платёжный аккаунт (банковскую карту), нажмите «Создать API-ключ» и сохраните секрет (повторно его не показывают), а идентификатор каталога скопируйте у названия каталога. Секрет кладётся в `YANDEX_SEARCH_API_KEY`, идентификатор каталога в `YANDEX_FOLDER_ID`. Тарифы смотрите в правилах тарификации Search API. Если Яндекс не ответит (неверный ключ, лимит), поиск идёт по Tavily, а в статусе будет причина.

### Свои демо-данные

```bash
python -m app.snapshot "сыр моцарелла" "Санкт-Петербург" --keywords моцарелла сыр
```

Гонит настоящий конвейер и сохраняет результат в `demo/*.json`. Демо-режим нужен, чтобы прототип не зависел от лимитов API у проверяющего. Пример КП (`demo/offers_demo.json`) явно вымышленный: компания «Образец-Мука» с доменом `.example` и пометкой в названии.

## Ограничения

- Проверка цитат подтверждает, что фрагмент есть в источнике, но не то, что значение из него следует. Поэтому в карточке есть «источник» и цитата для ручной проверки.
- Сайты, которые строятся JavaScript'ом, читаются хуже: страницы берутся без браузера.
- PDF-прайсы с сайта читаются только с текстовым слоем (сканы пропускаются), до 8 МБ, из каждого берутся первые ~15 000 знаков. Полный длинный прайс стоит загружать как КП: тогда позиции попадут в историю цен.
- Фильтр по минимальному заказу сравнивает рубли, если сумма есть в тексте минималки, и килограммы, если вес указан; если у поставщика минималка в других единицах или словами, он не отсеивается.
- Сканы и фото КП читает модель: цитату по тексту проверить нельзя, такие позиции помечены «не проверено по тексту».
- Загрузки КП на публичном демо ограничены дневным лимитом и 8 МБ на файл.
- Данные могут устареть, перед заказом их надо уточнять напрямую.
- Выдача поиска меняется от запуска к запуску (формулировки запросов, источники), число разбираемых сайтов ограничено `MAX_SUPPLIERS`.
