# Снабженец-ассистент

Сервис для поиска и сравнения поставщиков продуктов питания: ингредиенты, готовая продукция, упаковка.
Вводите товар и город, получаете карточки поставщиков с контактами, условиями и оценкой, а в конце — шорт-лист, письмо-запрос КП и выгрузку в Excel.

**Главный принцип: никаких выдуманных данных.** У каждого поля есть ссылка на страницу и дословная цитата. Если на сайте поля нет, сервис пишет «не указано — уточнить» и добавляет вопрос в письмо поставщику.

## Как это работает

```
запрос (товар + регион + фильтры)
  → Claude Haiku расширяет запрос (синонимы, «оптом», «производитель»)
  → Tavily: список сайтов, агрегаторы и маркетплейсы отсеиваются
  → загрузка главной + страниц «контакты / доставка / опт / документы»
  → Claude Haiku извлекает поля по строгой схеме (tool use), к каждому — цитата и URL
  → проверки кодом (без LLM):
        цитата реально есть на странице, иначе поле отбрасывается
        телефон: формат РФ и цифры есть на странице; email: валидный и есть на странице
        ИНН берётся регулярным выражением
        дубли склеиваются по ИНН и телефону
  → оценка 0–100 по правилам с понятными причинами («+ в вашем регионе; − нет цен»)
  → SQLite: кэш страниц, поставщики, результаты, шорт-лист
```

| Модуль | Что делает |
|---|---|
| `app/search.py` | расширение запроса, Tavily, чёрный список агрегаторов |
| `app/fetch.py` | загрузка страниц, очистка, поиск внутренних страниц, кэш |
| `app/extract.py` | извлечение через Claude по JSON-схеме |
| `app/verify.py` | проверка цитат, телефонов, email, склейка дублей |
| `app/score.py` | оценка и фильтры |
| `app/letter.py` | письмо-запрос КП (шаблон + необязательная правка Sonnet) |
| `app/export.py` | Excel / CSV |
| `app/pipeline.py` | оркестрация живого поиска и демо-режима |
| `static/index.html` | интерфейс (одна страница, без сборки) |

## Почему веб-сервис

Сравнивать поставщиков удобнее таблицей. Шорт-лист со статусами и заметками нужен в течение нескольких дней, а ссылкой можно поделиться с коллегой. Telegram-бот подходит позже как канал уведомлений («пришёл ответ», «цены устарели»), но не как основной экран.

## Оценка

Прозрачные правила, а не «чёрный ящик». Максимум 100 баллов: регион 30, контакты 20, минимальный заказ 15, документы 15, доставка 10, цены 10. Неизвестное поле не штрафуется нулём «молча»: оно попадает в минусы и в вопросы письма.
Фильтры (нужны документы, минималка не больше N кг, доставка в мой регион) скрывают не подошедших, но их можно показать.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt     # Linux: .venv/bin/pip
copy .env.example .env                              # впишите ключи
.venv\Scripts\python -m uvicorn app.main:app --port 8000
```

Откройте http://localhost:8000. Без ключей работает демо-режим (готовые результаты из `demo/`).

Переменные окружения: `ANTHROPIC_API_KEY`, `TAVILY_API_KEY`, а также `MODEL_EXTRACT`, `MODEL_WRITE`, `MAX_SUPPLIERS`, `LIVE_DAILY_LIMIT` (дневной лимит живых поисков на сервере, по умолчанию 20), `DB_PATH`.

### Свои демо-данные

```bash
python -m app.snapshot "сыр моцарелла" "Санкт-Петербург" --keywords моцарелла сыр
```

Гонит настоящий конвейер и сохраняет результат в `demo/*.json`. Демо-режим нужен, чтобы прототип не зависел от лимитов API у проверяющего.

### Тесты

```bash
.venv\Scripts\python -m pytest -q
```

### Деплой (VPS, systemd + nginx/Caddy)

Пошагово и одним скриптом (nginx + certbot): [DEPLOY.md](DEPLOY.md), `deploy/setup.sh`. Пример для Caddy:

`/etc/systemd/system/suppliers.service`:

```ini
[Service]
WorkingDirectory=/opt/suppliers
EnvironmentFile=/opt/suppliers/.env
ExecStart=/opt/suppliers/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
Restart=always
User=www-data
```

`Caddyfile`:

```
suppliers.example.com {
    reverse_proxy 127.0.0.1:8000
}
```

## Ограничения

- Проверка цитат подтверждает, что фрагмент есть на странице, но не то, что значение из него следует. Поэтому в карточке есть «источник» и цитата для ручной проверки.
- Сайты, которые строятся JavaScript'ом, читаются хуже: страницы берутся без браузера.
- Фильтр по минимальному заказу работает только когда он задан в килограммах.
- Данные могут устареть, перед заказом их надо уточнять напрямую.
- Яндекс Поиск API можно подключить в `app/search.py` рядом с Tavily, сейчас используется только Tavily.
